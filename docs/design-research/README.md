# Flexzora Design Research

Reusable research foundation for all future design work. The goal is not to copy
competitors — it is to understand the grammar users already trust, then out-execute
on the parts competitors leave weak.

## Files

| File | What it holds | Use it when |
|---|---|---|
| `competitive-landscape.md` | Teardown of every crew/gig staffing competitor: model, fees, UX, weaknesses | Positioning, pricing pages, landing copy, feature prioritization |
| `marketplace-patterns.md` | What top marketplaces share: trust grammar, conversion anatomy, listing/profile/checkout patterns | Designing any new page or flow |
| `prompt-library.md` | Ready-to-run prompts for AI-assisted design (component generation, teardown requests, redesign briefs) | Before prompting any design tool or agent |
| `tooling.md` | Map of design tools/MCPs (21st.dev, mobbin, etc.) and where each fits the workflow | Choosing the right tool for a design task |

## Operating principles

1. **Evidence over taste.** Every pattern in here is traced to a live product or
   published UX research. When we add a pattern, cite where it came from.
2. **Two products, two grammars.** Flexzora is a *marketplace* at the edge
   (landing, waitlist, profiles, listings) and an *operations tool* inside
   (dispatch, clocking, escrow, ops boards). Marketplace pages borrow from
   Airbnb/Upwork grammar; interior pages borrow from Linear/dispatch/SaaS grammar.
3. **Familiar but stand out.** Borrow structure (users learned it elsewhere),
   differentiate on surface (dark + amber live-events identity) and on capability
   (ops features nobody else ships).
